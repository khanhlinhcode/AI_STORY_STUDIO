The machine has Apple M1/8 GiB with Ollama `qwen3:4b` selected; no LoRA is active. A new six-scene worker preview completed all 14 steps using Edge Vietnamese voice and wrote 1920×1080 and 1080×1920 H.264/AAC MP4s (56.797 s each). It reused an existing episode script and a single NASA photo. `ffprobe` and SHA-256 confirmed both files, but QC blocked export on rights and repeated-image grounds. The local configuration has `AI_ADAPTER_MODE=fake` because no Replicate token is available, so it still cannot make six distinct AI illustrations. The older 640×360 and 360×640 previews remain historical artifacts.

Three NASA articles were generated through live Ollama for manual review. The geography keyword gate reported no Arctic/Antarctic reversal, but the first A-81 story repeated three pairs of scenes and overstated a shoreline claim; the new validators now reject those observed defects. A later A-81 rerun produced six distinct scenes but still overstated an uncertain underwater-shelf contact. Additional source-specific uncertainty checks were added afterward and pass offline tests; they have not yet passed a new live three-article acceptance run. The MP4s remain internal previews.
